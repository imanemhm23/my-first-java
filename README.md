# My First Java Project

Hi! I'm learning Java from zero and building a real project step by step.
This repository is my learning journey.

## Main project: Expense Tracker

An app where I can add expenses, see my total, and delete items.
I'm building it in stages, so I learn something new at each one.

## Roadmap

- [x] Stage 0: Set up Java, VS Code, Git and GitHub
- [x] Stage 1: Java basics (variables, if/else, loops, methods, classes)
- [x] Stage 2: Console expense tracker (add, list, delete, save to a file)
- [ ] Stage 3: Add a database (SQL)
- [ ] Stage 4: Turn it into a web app with Spring Boot and user login
- [ ] Stage 5: Put it online so anyone can try it

## Stage 2 features

- [x] Menu with a do-while loop
- [x] Read input with Scanner
- [x] Add expenses (ArrayList)
- [x] Show all expenses
- [x] Calculate the total
- [x] Delete an expense
- [x] Save to a file and load it again

## How to run

1. Open the project in VS Code (with Java 21 installed)
2. Run `Menu.java`
3. Choose a number from the menu:
   1) Add expense, 2) View expenses, 3) Total, 4) Delete, 5) Exit
4. Choose 5 to exit. Your expenses are saved in `expenses.txt` and loaded the next time you start.
